# FirstNinety — Onboarding Orchestrator (30/60/90)

AI-assisted onboarding for People teams: personalised 30/60/90 plans, automated logistics across Google Calendar, Gmail, Slack and Notion, and day-30/60/90 checkpoints that flag the gap between how managers and new hires see the first months.

**Module 1 of a People & Culture portfolio platform** (Onboarding → Performance & Calibration → Org Health).

> Demo mode uses a fictional company (Brightfold) and fully synthetic people and data.

## Screens
- **Cohort** — every hire from pre-boarding to day 90, with tasks and flags
- **Hire profile** — AI summary, checkpoints (hire vs manager), goals, tasks, Week 1, automations
- **Insights** — perception gap, time to first contribution, overdue by owner, managers
- **Integrations log** — previews of every Slack message, email, invite and task (simulated)
- **New hire** — generate and launch a personalised plan

## Stack
Next.js (App Router) · Tailwind · Vercel · Supabase (next) · LLM API (next) · Google / Slack / Notion APIs (next)

## Ethics
Flags describe the onboarding experience, not a prediction about a person. AI drafts, the People Partner decides.
